# Project context and stable vocabulary

This file is the short, shared language for code, traces, APIs, documentation, and reviews.
It describes stable meanings, not a promise that every backend uses the same implementation.
Normative wire and output details live in the documents linked from
[`docs/index.md`](docs/index.md).

## Scope

`fisheye-handpose` reconstructs metric 21-landmark hand poses from hardware-timestamped,
calibrated stereo fisheye video. It is independent of the existing VLA pipeline. The core
geometry package does not import the CUDA/OpenMMLab worker, and the inspectors never write to
pipeline runs.

## Capture and identity

| Term | Stable meaning |
| --- | --- |
| data item / session | One logical stereo capture directory with calibration and one or more complete video/timestamp parts. |
| part | One contiguous left/right video and timestamp segment inside a session. Part numbering is structural and ordered. |
| synchronized pair | One left and one right sample matched monotonically and one-to-one by hardware timestamp within the configured skew. |
| `item_id` | Safe catalog identity for the source data item. |
| `run_id` | Human-selected or generated identity for one attempt within an item; it is not globally unique. |
| run | One non-overwriting pipeline attempt under `runs/<item_id>/<run_id>/`. |
| `run_key` | API-only opaque identity derived from a run's catalog-relative path. |
| `frame_id` | Lossless source identity for a synchronized pair, potentially including its part. |
| `frame_index` | Global presentation-order display/index value within a run; not a stable API key. |
| `frame_key` | API-only opaque identity derived from the exact `frame_id`. |

## Geometry and image spaces

| Term | Stable meaning |
| --- | --- |
| native distorted | Original fisheye sensor pixels. RTMDet always consumes this space in the current H20 worker. |
| undistorted | Per-camera debug/QA image after removing fisheye distortion; not automatically a model input. |
| stereo rectified | A calibrated stereo QA/debug space in which epipolar geometry is checked. Full-frame rectification is not the mandatory pose-model image. |
| virtual-perspective crop | A hand-centred pinhole view generated by ray mapping from a native-fisheye proposal. It is the opt-in `virtual_perspective_kb4_v1` RTMPose profile. |
| pixel space | A named coordinate system attached to 2D evidence. Native, crop, undistorted, and rectified pixels are never interchangeable. |
| `T_B_from_A` | Transform that maps `X_A` into frame B: `X_B = R @ X_A + t`. |
| output 3D frame | Named camera or rig frame using OpenCV axes: `+x` right, `+y` down, `+z` forward. |

Internal timestamps are integer nanoseconds and internal lengths are metres. Calibration
translation units and extrinsic direction must be supplied explicitly because the source
Orbbec YAML does not declare them.

## Perception and pose stages

| Term | Stable meaning |
| --- | --- |
| proposal / candidate | A detector result considered for pose and stereo association. Recovery candidates are provisional, not final hands. |
| native view evidence | Model-native 2D evidence with an explicit source pixel space and joint-set provenance. |
| canonical view evidence | Evidence mapped explicitly into the canonical landmark semantics; fusion consumes only this boundary. |
| cross-view association | A decision that links at most one candidate per camera into a hand group, while preserving unmatched evidence. |
| Raw / `RAW_FUSION` | Immutable metric 3D observation produced from current calibrated image evidence. Later stages never overwrite it. |
| MANO / `KINEMATIC_REFINEMENT` | Optional kinematic estimate derived from Raw evidence. Rejection remains explicit and falls back without relabelling Raw. |
| stable / `TEMPORAL_REFINEMENT` | Timestamp-aware output derived from Raw or accepted MANO input. The current baseline is causal EMA, not Temporal MANO optimization. |
| `fhp21/v1` | Canonical ordered 21-landmark output contract. It is an operational landmark definition, not a claim of unique anatomical observability. |

Validity, evidence source, estimate stage, estimate kind, confidence/uncertainty, visibility,
and handedness are independent fields. `NOT_PRODUCED` means no artifact exists for that stage;
it must not be represented by a fabricated placeholder pose.

## Trace and inspection

| Term | Stable meaning |
| --- | --- |
| canonical trace | Append-only `run_manifest.json`, `trace.jsonl`, optional `run_summary.json`, and content-addressed blobs. |
| single writer | Only the core `RunArtifactWriter` mutates a canonical run. Worker output is validated staging data imported through that writer. |
| ACTIVE | Resumable run that may still be appended by its single writer. |
| COMPLETED / FAILED | Finalized run; records and referenced blobs are immutable and integrity-checkable. |
| legacy viewer | Small, self-contained, single-run UI served by `fisheye-handpose trace-serve`; useful for a local synthetic demo. |
| React inspector | Normal multi-item operator UI backed by the read-only FastAPI catalog. |
| project contract | Language-neutral shared identifiers and FHP21 topology in `contracts/project-contract-v1.json`; checked-in Python and TypeScript views are generated, never edited directly. |

## Non-negotiable invariants

- Pair frames by hardware timestamp, never by frame index alone.
- Never guess calibration units or extrinsic direction.
- Keep every 2D coordinate attached to its exact pixel space.
- Keep Raw observations immutable and preserve provenance through refinement and export.
- Keep CUDA/OpenMMLab dependencies outside the Python 3.11 core process.
- Keep one canonical writer per run and validate every imported worker artifact.
- Change shared stages, statuses, schema/mapping IDs, and FHP21 topology through the canonical
  project contract, then regenerate every runtime view.
- Never commit source captures, generated runs, model weights, MANO files, or private manifests.
